## Instalasi
1. Clone repo: `git clone https://github.com/biillskiii/take-home-test_mohammad-nabiel-dwi-ananda`
2. Masuk folder: `cd take-home-test_mohammad-nabiel-dwi-ananda`
3. Install dependencies: `npm install`

## Cara Pakai
Jalankan: `npm start`
Buka browser di: `http://localhost:5173`
